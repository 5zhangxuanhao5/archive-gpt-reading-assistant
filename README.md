# GPT阅读助手 · 1.5.3

## 安装到 Edge 和 Chrome

1. 解压 ZIP，把 `yueji-edge` 文件夹放到准备长期保留的位置。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`，打开「开发人员模式」。
3. 点击「加载解压缩的扩展」或「加载未打包的扩展程序」，两边都选择同一个直接包含 `manifest.json` 的 **yueji-edge** 文件夹。
4. 刷新 ChatGPT 网页，右侧会出现「历史 / 目录 / 笔记」。浏览器工具栏的插件图标也能打开笔记。

[Edge 官方本地安装说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)

## 从旧版更新

用新版文件覆盖你原来加载的 `yueji-edge` 文件夹。打开 `edge://extensions` 或 `chrome://extensions`，对本插件点击「重新加载」，然后刷新 ChatGPT 网页，并重新打开笔记侧栏。版本号应为 **1.5.3**。保留原插件安装记录即可保留笔记和文件夹设置，无需卸载或重新选笔记库。本地组件继续保留原来的文件夹配置。

1.5.3 修复网页内切换聊天后目录被拒收的问题。目录按标签页独立更新，切换标签、窗口或移动标签到新窗口时重新获取当前回答；流式标题、正文显隐和滚动阅读位置变化均会触发更新。无当前回答时清空目录，不显示其他聊天的缓存。目录来源校验只读取原有两个 GPT 网站的当前标签地址。

笔记由文字、图片、GPT 引用三类独立框组成。从更早版本更新时，旧正文与摘录会按原顺序迁移，原文出处保留。右侧三个入口为「历史 / 目录 / 笔记」；返回入口只在有可恢复阅读位置时出现。悬浮区缩小，窄屏时收成小入口，鼠标移上展开。

1.5.2 将 ChatGPT 中的笔记改为网页内嵌侧栏，去掉浏览器原生侧栏的插件名称栏，并把重命名放进编辑工具区。新版还改进协同更新、空框引用插入、目录深层结构，以及图片放大和拖放。1.5.2 把阅读定位改为每个聊天单独持久保存，进一步收紧笔记标签和工具栏。

## 一次设置，持续保存到电脑

此版本提供 **macOS 本地文件组件**，用来记住笔记文件夹并持续读写，避免每次重启浏览器都重新请求文件夹权限。

在本次制作这台 Mac 上，组件已经安装完成。首次打开笔记时点击「选择文件夹」，直接选择你要使用的笔记目录。需要新建时，可在系统文件夹选择窗口里自行创建。插件不会自动在选中的目录里再套一层笔记库文件夹，已有的 Markdown 文件也会读入。

如果把插件移到**另一台 Mac**，先双击 `native/安装本地文件组件.command` 安装组件，再加载插件并选择文件夹。组件安装在当前用户目录里，不需要管理员权限。电脑需要 Python 3。

之后打开、关闭、重启 Edge 或 Chrome，插件都会直接使用记住的位置。只有你主动更改位置、删除或移动笔记库、移除组件，或操作系统撤销了文件访问权限时，才需要处理连接问题。

组件通过浏览器本机消息机制连接，不启动网络服务器。笔记文件读写限制在你选择的笔记库，共享备份缓存在本地组件目录；路径越界和符号链接到库外的内容会被阻止。[Edge 官方本机消息说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/native-messaging)

未安装组件时，设置页也提供「其他保存方式」：浏览器文件夹接口。此方式的权限是否持久由浏览器控制，因此持续保存建议使用本地组件。

## 两个浏览器共用一份笔记与缓存

Edge 和 Chrome 使用同一份扩展文件、同一个已选择的笔记目录、同一个本机文件组件。Chrome 首次打开笔记会沿用现有位置，不需要再选一次文件夹。

笔记备份、图片缓存、历史目录索引保存在 `~/Library/Application Support/Yueji/cache.sqlite3` 中。旧浏览器中的插件缓存会自动迁入；确认迁移成功后，只移除已迁移的插件缓存条目。相同内容去重，不同内容保留导入副本。浏览器各自的标签页、面板状态与网站自身的缓存仍由各浏览器管理。

两边打开同一篇笔记时，会自动同步修改：可见笔记页每 200 毫秒检查共享库的版本号，发现变化后读取更新，不刷新网页也能收到另一边的文字、图片和引用。200 毫秒是检查间隔；实际显示时间还取决于保存和读取过程。没有变化时不会重复重建编辑页，收到更新时保留未变的框、编辑器 DOM、焦点和滚动位置，并映射文字光标。中文输入法组合期间延后应用，避免打断输入。

编辑不同框或同一框的不同位置，会合并到同一篇笔记；同一位置无法安全合并的替换，会保留双方内容。此协同范围是同一台电脑上的浏览器和笔记窗口。

共享组件连接失败时会报告保存失败并保留当前输入供导出，不另建一套浏览器笔记库。Markdown 文件与共享备份均留在电脑上；扩展不会自动上传笔记。你主动将图片拖入 ChatGPT 时，由网页接收图片附件。

## 历史、回答目录与阅读位置

- **历史**：列出当前聊天中你的发问，支持搜索。鼠标放上历史按钮会展开，移出目录区域后收起。点击条目跳到对应提问，悬浮条目显示完整文字。
- **目录**：覆盖笔记页，按当前回答的实际结构列出标题、嵌套列表和正文段落，层级数量随回答变化，最多 24 层、2,000 个条目。标题跳号时不会凭空增加父级，目录可展开到最底层文字；没有标题的回答也能列出正文。默认显示一级，选择较深层会自动包含前面的层级，取消中间层会同时隐藏更深层级。滚动到另一个回答、切换聊天或继续生成内容后自动更新。点击条目返回聊天中的对应位置；点击「笔记」恢复笔记编辑。
- **返回**：在当前聊天的提问或回答正文中单击，设置本聊天的阅读定位。定位细到文字行、段落、列表项、表格单元格与代码行，点击处左侧会出现一个小圆点。滚动到别处后，点击「返回」回到这个点。再次普通单击会替换本聊天的定位。
- 每个聊天只保存自己的一个定位，切换聊天时不带入旧定位；切回、刷新或重新打开原聊天后会从后台恢复。定位存在同一份本机共享缓存中，Edge 和 Chrome 可读取；不需要重新选择笔记目录。
- 拖选、双击选字、点击清除选区，以及复制、链接、追问按钮和「插入到当前笔记」等操作不会改写定位。
- 先单击设置定位，再选中文字使用网页「向 GPT 提问」。发送这次追问后，未开启自动返回时可点「返回」；开启自动返回时会回到先前点击的点。选择的文字只用于追问，不会变成新定位。普通发问不触发自动返回。
- 原定位的消息尚未加载时，会加载并查找原文；消息已被删除、改写或失去访问权限时会提示，保留原记录。
- 在笔记设置中可关闭自动返回，仅使用右侧「返回」按钮。

打开历史时，插件会在一个临时后台聊天标签页里滚动到开头，再逐段扫描。补全过程不会滚动当前阅读页面，临时标签页完成后自动关闭；不要手动关闭这个后台标签页，若关闭可点击「继续补全」。如果主动打开后台标签页，扫描会暂停，让你正常使用它。

扫描期间显示「正在后台补全」，完成后显示「已补全至开头」。即使旧消息被网页卸载，提问仍按顺序保存在历史；文字相同的多次提问依据消息 ID 分开保留。点击未显示的早期条目会自动加载并定位。历史只保存在本机插件内，不写入笔记文件夹，也不向其他服务上传。

遇到网络错误、登录失效、聊天过长或加载超时，保留已读到的部分并显示「继续补全」，不会把未完成的扫描显示成完整目录。切换或关闭聊天会停止它的后台任务。阅读定位属于各自聊天，切换时在后台保留原聊天记录，并读取新聊天的记录。

## 多标签与多层文件夹

在 ChatGPT 中，笔记直接嵌在网页右侧，没有浏览器原生侧栏的插件标题行。顶部保留新建、文件夹、文件列表开关和设置，深浅色跟随 ChatGPT。拖动左侧边缘可调整笔记宽度。文件列表默认收起，鼠标放上顶部文件列表图标会覆盖展开；点击笔记或移出文件列表区域后收起，正文区域的高度不会被文件列表挤占。

新建笔记时可以选择存放文件夹，在名称输入框按 Enter 即可创建；中文输入法正在选字时，Enter 只确认输入，不会提前创建。新建文件夹时可以选择父文件夹，因此支持多层结构。编辑格式工具区的重命名按钮可修改名称或移动笔记；名称和路径不再单独占一行。

点击文件列表中的多篇笔记，就会同时打开多个笔记标签。多标签宽度约 94–104 像素，长名称省略显示，悬浮可查看全名；标签较多时可横向滚动。标签上的 × 只关闭标签，笔记仍保留。不同 ChatGPT 聊天共用同一个本地笔记库。

## 分框笔记与 Markdown

每个文字、图片和 GPT 引用分别占一个框。最上面、最下面及任意两框之间只有小加号；点击在该位置建立空框，输入文字后归为文字框。没有输入的空框在点击别处、切换笔记或预览后自动去除；前往聊天选中文字准备摘录时，会暂时保留刚选中的空框位置，把引用放进这个框。正在导入图片的框会保留，已有引用和图片不会被当作空框删除。

文字和 GPT 引用可直接输入完整 Markdown、撤销重做；顶部按钮作用于当前编辑的框，鼠标悬浮显示中文解释。「更多」悬浮只展开格式条目，不再叠加工具提示。预览支持常规 Markdown、表格、待办、脚注与 KaTeX，并过滤危险 HTML。

在空框里使用 ⌘V（Windows 为 Ctrl+V）粘贴图片，会变成图片框；在已有文字或引用中粘贴图片，会在它下面新增图片框，原内容保留。每张图片单独一个框，支持常见 PNG、JPEG、GIF、WebP、BMP、AVIF，每张最多 20 MB。文字粘贴默认纯文本，删除空行，其余换行及缩进保留。

三类框默认颜色不同。设置中的「默认框颜色」调整整类颜色；鼠标移到单个框右上角的颜色按钮，可以单独修改它的颜色。移除框后可使用提示中的「撤销」。原文返回按钮在鼠标移上引用框或键盘进入框时显示。

点「预览」，顶部的「文字 / 图片 / 引用」与「编辑 / 预览」按钮共用一行，默认勾选三类，正文占满宽度。预览中的相邻框留有 12 像素间隙；编辑时仍只有加号分隔。取消勾选只隐藏对应类型，不删除内容，也不改变电脑上的 Markdown。回到编辑模式可继续编辑全部框。

点击编辑或预览中的图片，会在左侧聊天区域放大显示，右侧笔记仍可使用。鼠标移动时右上角显示关闭按钮，闲置约 900 毫秒后隐藏；关闭或按 Escape 回到原聊天画面，原阅读位置保留。图片也可通过键盘 Enter 或空格打开。

可以将笔记中的图片拖到 ChatGPT 的输入区域。扩展会把图片作为真实 `File` 交给网页，而不是粘贴图片链接，并在跨框架拖动时恢复图片文件内容。插件不会自动发送提问；确认网页显示了附件后，由你点击发送。真实 ChatGPT 网页是否接收附件，仍需在当前账号中验证。

图片的实际文件保存在笔记库根目录 `.gpt-reader-assets` 下，Markdown 使用相对链接；复制或备份整个笔记文件夹时请一起保留此目录。单篇「导出」生成含内嵌图片和出处的 Markdown；设置中的「导出备份」包含框、出处、颜色和图片数据。正文 Markdown 文件仍限制约 8 MB，图片资产独立计算。大于该限制的单篇内嵌导出不适合重新作为普通 Markdown 导入；完整备份请复制整个笔记库。

## GPT 引用与跨聊天返回原文

先打开笔记并选中一篇笔记，再在回答或提问中选中文字，就会出现「插入到当前笔记」。选中空框时，引用直接填入这个框，位置不变；选中已有内容的框时，引用接在它下面，没有选中框时加到末尾。引用可直接编辑 Markdown，只修改笔记；小回车「↵」定位到原始出处，改写引用后出处仍保持最初的原文。

同一篇笔记可收集不同聊天的内容。原聊天还开着时会切回它；关闭后会重新打开并等待消息加载。来源和框信息以不可见注释随 `.md` 保存，用其他 Markdown 编辑器仍可正常阅读。原聊天被删除、消息被改写或账号失去访问权限时，可能无法精确定位。目录覆盖笔记时隐藏插入笔记选项，回到笔记后恢复。

## 保存与外部修改

底部会显示「已保存到电脑」「正在保存」或「已保存本地备份 · 待写入文件夹」。鼠标悬浮保存状态可查看问题原因。

每次编辑都会立即发送到插件本地库，再写入电脑文件。关闭聊天标签页后，笔记仍保留。

从电脑直接放入笔记库或子文件夹的 `.md` 文件，笔记面板会在约两秒内自动识别；在 Obsidian 等软件中修改文件后，也会自动读取更新。设置中的「读取文件夹更新」仍可手动立即检查。插件发现外部文件改动时不会直接覆盖；存在未同步的本地修改时，会保留副本。Edge、Chrome 或多个笔记窗口编辑同一篇笔记时，会自动合并不同框和文字位置的改动。无法安全合并的同一处替换，会在同一篇笔记中保留双方的框，并短暂提示。旧版编辑客户端仍使用整篇冲突副本保护。

可通过设置「导出备份」导出包含正文、文件夹和出处的 JSON。实体 `.md` 文件也可以直接复制备份。卸载浏览器插件不会删除你选择的笔记文件夹，也不会删除本机共享备份。

读取文件夹里的普通 `.md` 文件；隐藏文件和文件夹会跳过。单篇文件上限约 8 MB。

## 更新与卸载组件

插件文件夹请长期保留。更新后在 `edge://extensions` 和 `chrome://extensions` 点击重新加载，再刷新 ChatGPT。插件使用固定 ID，移动安装文件夹后不会因路径变化而改变组件连接身份。

需要移除本地组件时，用 Python 3 运行 `native/uninstall.py`。它只移除两个浏览器的本机组件注册，保留笔记文件夹、共享缓存和文件夹配置。

## 验证范围

当前版本的独立 Edge、Chrome 回归结果见随包「验证说明.md」，包含分框编辑、图片粘贴事件与重启持久化、真实临时目录的图片及 Markdown 写入、旧笔记迁移、预览筛选、颜色、并发保存、历史补全、当前回答的深层目录、网页内嵌侧栏及图片预览。图片拖放验证以模拟 ChatGPT 页面中接收真实文件为范围，不代表真实 ChatGPT 账号已成功上传附件；实际网页上传仍需现场验证。

自动测试使用模拟 ChatGPT 页面，不能等同于真实账号全面验证。系统真实剪贴板快捷键及首次系统文件夹选择器未自动操作；网页结构变化可能需要调整识别。

ChatGPT 页面优先使用网页内嵌笔记；主笔记区保持打开，方便连续输入和摘录。无法使用网页内嵌区时，工具栏入口会打开独立的笔记标签页。

## 开发与第三方库

运行插件不需要安装任何 JavaScript 依赖。编辑器和预览库已经打包在 `vendor`。对应开发源码与依赖锁文件在 `development`，第三方许可证在 `THIRD_PARTY_NOTICES.txt`。
