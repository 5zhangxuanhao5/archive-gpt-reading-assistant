# GPT阅读助手 · 1.6.0 免组件版

给 ChatGPT 网页加上回答目录、提问记录、阅读返回和分框 Markdown 笔记。

**加载浏览器插件即可使用，不需要 Python、本地组件、终端命令或管理员权限，也不需要先选择笔记文件夹。**

## 安装

1. 下载 1.6.0 安装包，解压，把 `gpt-reading-assistant` 文件夹放到长期保留的位置。
2. Chrome 打开 `chrome://extensions`，启用开发者模式，点击“加载已解压的扩展程序”；Edge 打开 `edge://extensions`，启用开发人员模式，点击“加载解压缩的扩展”。
3. 选择直接包含 `manifest.json` 的文件夹。
4. 刷新已打开的 ChatGPT 网页，在右侧使用目录、提问记录、笔记与返回。

尚未上架扩展商店，仍需手动加载扩展。桌面 Chrome / Edge 为验证目标；其他 Chromium 浏览器需兼容相关扩展和文件接口，Firefox、Safari、手机端不在本次支持声明中。无额外运行时依赖的代码可跨平台，但 Windows / Linux 的真实操作系统流程尚未验收。

## 用法

- **目录**：查看当前回答的结构，按标题、列表或正文快速跳读。阅读其他回答时目录随之更新。
- **提问记录**：界面中的“历史”，列出当前对话的提问，点击返回对应一轮。长对话补全使用临时后台标签，遇到中断可继续。
- **笔记**：点“＋ 新建”直接开始，文字、图片和 GPT 引用分框编辑，支持 Markdown、公式、表格、待办、预览和文件夹。选中网页文字，点“插入到当前笔记”，引用可点“↵”回到出处。
- **返回**：阅读正文时单击留下定位，追问或再次提问后点“返回”接着读。选中文字追问后的自动返回可在设置中开关；普通再次提问使用手动返回。

## 自动保存和备份

笔记、图片、提问索引及阅读位置自动保存在**当前浏览器的扩展数据库**，页面关闭和正常重启浏览器后保留。状态显示“已保存到此浏览器”。同一浏览器的多个聊天可以共用笔记并合并编辑。

- Chrome 和 Edge 各自保存自己的数据，**不跨浏览器或跨设备自动同步**。
- 单篇笔记可导出为带内嵌图片及来源信息的 Markdown。
- 在设置中“导出完整备份”，会生成包含笔记、图片及文件夹的 JSON；在另一浏览器“导入备份”可恢复这些内容。导入添加副本，保留原有笔记；损坏文件会拒绝导入。完整备份文件上限 64 MB，图片总量上限 48 MB，单张图片 20 MB。
- 完整备份用于笔记迁移，不包含聊天提问索引、阅读位置及浏览器 UI 偏好。引用指向的原聊天仍需接收浏览器账号有权限访问。
- **卸载扩展、清除扩展数据或更换电脑前，先导出完整备份。** 浏览器本地保存不等于云备份。

可选的“绑定笔记文件夹”只用浏览器内置文件接口，把 Markdown 和图片额外写到电脑目录。它无需本地组件，但可能在浏览器重启后重新要求文件夹授权。未授权或写入失败时，浏览器中已提交的笔记保留，状态会提示文件夹待同步。设置中可以改回“仅保存在浏览器”，原文件夹不删除。

## 与旧版共存

免组件版使用独立固定扩展 ID，可以与 1.5.x 共存，**不读取原本机组件、共享缓存或旧笔记库**。从旧版迁移时，在旧版设置里导出完整备份，再在新版导入；原版及其笔记保持原样。旧版已经打开的网页应只启用其中一个阅读助手，避免双重界面。

## 权限和隐私

只有 `storage` 和 `unlimitedStorage` 扩展权限，网页访问限制为 `chatgpt.com` 与旧地址 `chat.openai.com`。没有 `nativeMessaging`，不会调用外部程序，不向开发者服务器上传笔记或聊天内容。用户主动上传给 ChatGPT 的图片仍按 ChatGPT 自身的数据处理方式接收。

插件不提供账号、会员、模型额度或网络连接。网页结构调整可能影响定位。真实 ChatGPT 图片拖放接收没有在本版本中全面验证，不能当作稳定上传能力。

## 开发和验证

运行成品不需要 npm 或其他依赖。编辑器、Markdown 渲染、公式和安全过滤库已随包提供，许可证见 `THIRD_PARTY_NOTICES.txt`；仅重新构建编辑器才需要 `development` 下的开发依赖。

`tests/standalone.e2e.cjs` 在隔离的浏览器配置目录验证首次使用、保存、图片、完整备份、导入失败保护、并发编辑及重启。安装 Playwright 后运行 `node tests/standalone.e2e.cjs`；可用 `PLAYWRIGHT_MODULE`、`CHROME_EXECUTABLE`、`MSEDGE_EXECUTABLE` 指定测试环境。

源码历史保留旧版，当前成品以 1.6.0 安装包为准。
